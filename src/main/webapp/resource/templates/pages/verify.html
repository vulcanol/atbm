Xác minh tính hợp lệ của chữ ký số

Cung cấp file PDF gốc, chữ ký số và khoá công khai. Kết quả cho biết tài liệu có bị thay đổi sau khi ký không.

Kéo thả hoặc chọn file PDF
File PDF gốc cần xác minh
Hướng dẫn

Lấy chữ ký số

  1. Ký số tài liệu tại trang Ký số
  2. Vào Tài liệu → Nhấn Chi tiết → Sao chép chữ ký Base64

Lấy khoá công khai

  1. Vào trang Quản lý khoá RSA
  2. Nhấn "Sao chép Public Key" và dán vào đây
Thuật toán xác minh:  hash' = SHA-256(PDF)  |  hash = Decrypt(signature, publicKey)  |  Kết quả: hash == hash'
